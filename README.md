# 多模态数据运营与 AI 协作实践

本作品集围绕数据质量、执行流程与人机交流展开。先阅读案例与规则，再查看计算和证据附件。

| 案例 | 解决的问题 | 方案与成果 | 成果性质 |
|---|---|---|---|
| [人像数据质检](cases/portrait-quality.md) | 困难样本误排除、好批误退、差批误收与返工成本 | 风险导向过程质控、双风险抽样验收、成本敏感性分析 | 实际工作场景资料下进行的方案分析与应用设计；可独立复算 |
| [多 Agent 协作](cases/multi-agent.md) | 重复调用、交接缺口、执行异常与质量状态混淆 | 任务编排、独立复核、检查点与交付证据追踪 | 个人工程历史记录复盘；AI辅助实现 |

## 人机交流规则

[人机交流中的意图对齐与推进范围管理](communication-rules/README.md)：从实际对话问题出发，整理七类交流场景、双向提问、范围确认和反馈维护机制。包含匿名形成过程、精选原话与完整规则；以Codex为首个试用环境，预期价值与验证事实分开说明。

## 快速阅读

- **人像项目**：联合选择样本量与接收数，在指定质量水平上控制两类抽样风险。退回成本100人时/批的测算情景下，预计投入下降15.33%；成本低于约72.63人时/批时，新方案不更省。
- **多 Agent 项目**：已核对150条结构完整的课堂交付数据与关联方案复核记录；其中140条仍标记待人工复核。结构交付不等于语义验收，案例明确呈现这一质量缺口。
- **方法价值**：将质量风险、执行成本、异常和未完成工作写成可检查的记录，支持运营判断与后续改进。

## 作者与材料边界

个人项目实践，使用AI辅助方案讨论、实现与文档整理；不宣称全部代码或方法由作者独立原创。人像项目是在实际工作场景资料下进行的方案分析与应用设计，围绕数据质检与批次验收展开。成本假设与计算结果单独标注，不将预计收益写成已实现收益。公开版本仅包含精选案例、测算参数、复算代码与摘要，不包含原始任务账本、私密对话、课堂原始资料、真实人物图片、账号凭据或本机服务接口。

现有互动展示保持只读。历史运行记录与报告支持当时的过程复盘，不代表当前系统已经重新完成端到端测试。
