# 个人 AI 协作平台：Vibe Coding 作业展示板

这是“个人 AI 协作平台”的脱敏、只读、开源展示版。

它展示的重点不是“同时调用更多模型”，而是：

- 如何判断一个任务应该交给谁；
- 什么时候一个 AI 足够，什么时候需要独立复核；
- 如何借鉴“三省六部”的拟议、封驳与执行分离；
- 如何让执行结果带有测试、来源与人工审批证据；
- 如何诚实区分“已经证明的效率”与“尚未证明的假设”。

## 本地查看

这是一个不需要构建工具的纯静态网站。下载后直接打开 `index.html`，或者使用任意静态文件服务器。

例如：

```bash
python -m http.server 8000
```

然后访问 `http://127.0.0.1:8000`。

## 安全边界

本仓库只包含课堂展示所需的静态 HTML、CSS 和 JavaScript：

- 不包含个人 AI 协作平台后端；
- 不包含任务数据、知识库内容或本机路径；
- 不包含模型密钥或桌面执行能力；
- 不调用模型，不访问任何 API，不写入任何数据。
