# 证据说明

## 人像验收

inputs文件为模拟参数，results为标准库脚本复算输出。好批不合格数取floor(0.01N)，差批取ceil(0.03N)。模型假定随机不放回抽样、判定正确，且所有批次处于所选质量情景；不模拟判定者误差或多轮返工。

成本按“首验投入＋预计退回批数×一次退回处理总人时”计算。单条检查时长为模拟设定；每批退回成本在情景内相同。预计退回批数是重复情景下的期望，不是一次实际发生的小数批次。

最小样本量搜索只针对指定整数批量、质量点、接收概率与c/n≤2%约束。两质量点之间的行为不由这两个阈值单独保证。样本98%门槛不是总体质量保证。

## 多 Agent

公开材料为对本地历史账本、交付文件与报告的人工可读摘要。没有发布原始对话、完整任务数据或课堂样本。因此读者可以检查案例逻辑与范围，但不能仅凭公开摘要独立验证全部历史执行。具体证据等级见multi-agent-summary.md。
